# ArpanOS

[![Version](https://img.shields.io/badge/version-1.0.5.0-blue.svg)](https://github.com/UnknownCoder56/ArpanOS)
[![Platform](https://img.shields.io/badge/platform-Windows%20x64-lightgrey.svg)](https://github.com/UnknownCoder56/ArpanOS)
[![Language](https://img.shields.io/badge/language-QB64%20BASIC-orange.svg)](https://github.com/UnknownCoder56/ArpanOS)

A simple, user-friendly operating system simulation built with QB64 BASIC. ArpanOS provides a retro computing experience with MS-DOS like commands and a collection of useful utility programs.

## ⚠️ Important Information

**Universal Password**: `1647`  
*This password is required for accessing all applications and features within ArpanOS.*

## 🚀 Quick Start

1. **Download** the latest release from this repository
2. **Extract** all files to a folder on your Windows system
3. **Run** `ARPAN_OS.EXE` to start ArpanOS
4. **Enter password** `1647` when prompted
5. **Enjoy** exploring the various programs and utilities!

## 📋 System Requirements

- **Operating System**: Windows x64 (all versions)
- **Architecture**: 64-bit systems
- **Additional Requirements**: None - ArpanOS is fully portable
- **Note**: Does not modify your system or install additional files

ArpanOS comes with a comprehensive suite of built-in applications:

| 🖊️ Plotter | `plotter` | Create and visualize mathematical plots |

## 🎮 Usage Instructions

### Starting ArpanOS
1. Launch `ARPAN_OS.EXE`
2. Choose your display settings:
   - **Option 1**: Fullscreen mode (disable Windows UI)
   - **Option 2**: Windowed mode
   - **Option 3**: Exit
3. Enter the password: `1647`

### Navigation
- ArpanOS uses simple, MS-DOS like commands
- Type the command name (e.g., `calculator`) to launch applications
- Use intuitive navigation within each program

### Exiting Fullscreen Mode
If you choose fullscreen mode, press `ALT + ENTER` four times to return to Windows.
